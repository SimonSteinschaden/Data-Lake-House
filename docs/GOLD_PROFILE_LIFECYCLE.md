# Gold-Profile-Lebenszyklus

1. Daten werden erfasst.
2. Messprofile werden technisch analysiert.
3. Probleme werden kuratiert.
4. Ein ENSET-Mitarbeiter bestätigt die fachliche Korrektheit und das Inventar.
5. Die operative Qualität kann Gold erreichen.
6. Eine unveränderliche Gold-Profil-Version wird erzeugt.
7. Das Datenprodukt bleibt zunächst Draft.
8. Ein Berechtigter setzt es auf Released; später ist Archived möglich.

Kunden dürfen Daten liefern und korrigieren, aber keine fachlichen
Bestätigungen, Gold-Versionen oder Veröffentlichungen vornehmen.

Persistierte Analyse- und Kurationsdaten sind Eingaben der späteren
operativen Bewertung, aber selbst keine Gold-Freigabe.
